- 安装 Python 3.11+
- 安装 FFmpeg
- 安装 Manim 与 `manim-voiceover`
- 安装 Bun 或确认只通过现有 Node 工作流驱动 HyperFrames 相关命令

### 阶段 2：主 Agent 输入链路

- 接入 PDF 解析
- 接入笔记归档
- 实现研究总结与公式目录抽取

### 阶段 3：任务编排

- 实现镜头切分
- 实现 HTML / Manim / SVG 任务派发
- 实现长期/短期上下文真实落盘
